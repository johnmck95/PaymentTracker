A small learning project.

# Running The Project

From the project root, run `./start.sh`. Spins up the DB container, BE & FE.

## Frontend

- Angular, TypeScript
- `npm start` from `/angular-app` to start.
- localhost:4200

## Backend

- SpringBoot, Java
- `./mvnw spring-boot:run` from `springular/backend/demo` to start.
- localhost:8080

## Database

- MySQL, Docker container
- `docker compose up` from project root.
- localhost:3306
